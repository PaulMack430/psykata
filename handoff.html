01 — Overview

What Psykata Is

Psykata is an online martial arts training platform built around a structured curriculum across three levels: Beginner, Intermediate, and Advanced. The name blends PSY (psyche — the mental discipline side of martial arts) with KATA (the Japanese term for codified forms practised until they become instinct).

This handoff delivers a complete, production-ready frontend — three interconnected pages with a shared design system, fully responsive layout, and both light and dark theme support. No backend has been connected yet; that is the next phase of work.

02 — Deliverables

What Was Built

Landing Page

index.html

Full-height hero with headline and stat panel, a brand manifesto section, three-level strip navigation (Beginner / Intermediate / Advanced), and a call-to-action footer. Designed to convert visitors to members.

Training Library

videos.html

Tabbed video library with three levels. Each level features a prominent editorial card for the first lesson, followed by a grid of six video cards. Tabs switch via JavaScript with no page reload. Supports a ?level=beginner URL parameter so external links can deep-link to a specific level.

Member Login

login.html

Split-panel login page. Left panel is an atmospheric pitch area with the brand proposition and feature bullets. Right panel contains the login form with email/password fields, remember-me checkbox, forgot-password link, and a Google auth button placeholder. Form validation is wired up in JavaScript; the submit action is stubbed and ready for a real API call.

All colours are defined as CSS custom properties on :root in styles.css. Light and dark values are paired — changing a token updates both themes simultaneously. The dark palette is defined using prefers-color-scheme media query and data-theme attribute override.

Typography

Display — Cormorant Garamond
The mind perfects what the body repeats.
Used for: hero headline, section pull quotes, login pitch. Weight 300 italic. Loaded from Google Fonts.
UI Label — Barlow Condensed
Beginner · 01 · Training Videos
Used for: tabs, badges, stat numbers, eyebrows, file names. Weights 400, 600, 700.
Body — Barlow
Structured training for every level — from first stance to advanced kata mastery. Guided by expert instructors, practised on your own schedule.
Used for: all body copy, nav links, buttons, form labels. Weights 400, 500, 600.

Design Rationale

The choice of Cormorant Garamond — a refined, high-contrast serif — as the display face for a martial arts brand was deliberate. Most competitors use heavy aggressive sans-serifs. The tension between the elegant typeface and the combative subject mirrors what Psykata actually is: precision and mental discipline, not brute force. This is what distinguishes the brand visually.

The palette uses warm stone tones (not generic grey) in light mode and a warm near-black with brown undertones (not generic dark) in dark mode. The crimson accent is used sparingly — only on interactive elements and key brand moments — so it retains impact.

05 — Running the Project

STEP 01

Clone from GitHub

Pull the repository down to any machine.

06 — Repository

GitHub Setup

The project is version-controlled with Git and pushed to GitHub at github.com/PaulMack430/psykata. The initial commit contains all six files (README, CSS, JS, and three HTML pages).

To push future changes from a local machine, configure the remote with a GitHub Personal Access Token:

git remote set-url origin https://YOUR_TOKEN@github.com/PaulMack430/psykata.git git push -u origin master

Tokens can be created at github.com → Settings → Developer settings → Personal access tokens. The token needs repo scope.

07 — Next Steps

What Still Needs to Be Built

The frontend is complete. Everything below is backend work or content integration — none of it requires changes to the existing HTML/CSS structure.

Item Priority Notes
User authentication Required Replace the stub in js/main.js → initLogin() with a real auth call. Supabase Auth or Firebase Auth are good low-cost options.
Video hosting Required Placeholder thumbnails need real video embeds. Vimeo (privacy controls for members-only) or Mux (purpose-built for video platforms) recommended.
Members area / dashboard Required A post-login landing page. Could be an extended videos.html with progress state, or a separate dashboard.html.
Progress tracking Required Per-user lesson completion. Needs a database — Supabase (Postgres) pairs well with Supabase Auth.
Payment / membership Required Stripe is the standard choice. Can be added as a hosted checkout link with minimal backend work.
Content management Later Adding videos currently requires editing HTML directly. A CMS (Sanity, Contentful, or a simple admin page) would let non-developers manage the library.
SEO / metadata Later Open Graph tags, sitemap, and structured data for search engines.
Community / comments Later Mentioned in the brand copy. Could be a Discord integration or a lightweight comments system per video.

08 — Recommended Stack

Suggested Technologies for Phase 2

AUTH

Supabase Auth

Free tier, email + Google login out of the box, pairs with a Postgres database for progress tracking. One service handles auth, database, and file storage.

VIDEO

Vimeo Pro or Mux

Vimeo Pro allows domain-locked, members-only video embeds. Mux is purpose-built for video platforms with analytics and adaptive streaming — better long-term but more expensive.

PAYMENTS

Stripe

Industry standard. Stripe Checkout requires almost no backend — a payment link can be created from the dashboard and embedded as a button within days.

HOSTING

Vercel or Netlify

Both connect directly to the GitHub repo and deploy automatically on every push. Free tier is more than enough for this stage. A custom domain (psykata.com) can be connected in minutes.
